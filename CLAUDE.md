# CLAUDE.md

## Проект

`barbican` — CLI для проверки RBAC и изоляции тенантов в API мультитенантных платформ.

- **Модуль 1 (текущий):** матрица «роль × эндпоинт», privilege escalation, BOLA/IDOR, cross-tenant утечки.
- **Модуль 2 (позже):** evidence-pack по внешним стандартам. Добавляется регистрацией проверок, не переписыванием ядра.

## Стек

Node >=22.12 · TypeScript 6 (`nodenext`, strict) · commander 15 · vitest 4 · Biome 2 · pnpm 11 · lefthook + gitleaks.

Сборка — `tsc`, без бандлера. Версии точные, без диапазонов.

## Архитектурные инварианты

- `src/core` — чистые функции. Ни HTTP, ни файловой системы, ни глобального состояния. Вход: роли, эндпоинты, наблюдения. Выход: матрица и диффы. Тестируется на фикстурах без сети.
- JSON — единственный источник истины. HTML/PDF рендерятся из JSON отдельным шагом, а не генерируются по ходу проверок.
- Проверки — плагины через `CheckRegistry` (`src/core/checks/`). У каждой: `id`, описание, функция, маппинг на пункты внешних стандартов.
- Адаптеры (HTTP, парсер спек, троттлинг) — за интерфейсами в `src/adapters/ports.ts`. Замена реализации не должна трогать ядро.
- Пакет работает и как CLI (`bin`), и как библиотека (`exports`).

## Инварианты безопасности

- **Safe by default:** без явного `--unsafe-methods` выполняются только GET и HEAD (`SAFE_METHODS` в `src/core/types.ts`).
- **Троттлинг всегда включён:** лимит конкурентности, лимит запросов в секунду, общий потолок на прогон, экспоненциальный backoff, circuit breaker на серии 5xx/429, уважение `Retry-After`. Дефолты консервативные.
- **Тела ответов не сохраняются** по умолчанию — только статус-код, заголовки и факт доступа. Там PII клиента. Порт `HttpResponse` намеренно не содержит тела.
- **Внешние `$ref` в OpenAPI не резолвятся** — ни по http, ни по файловой системе. Защита от SSRF и path traversal. Требуется тест-доказательство.
- **Редакция чувствительных данных по хардкод-путям.** Пути редакции никогда не берутся из пользовательского ввода.
- **Scope обязателен:** без явно заданного allowlist хостов инструмент отказывается работать.
- **Секреты только через переменные окружения.** Ничего в репозиторий, ничего в логи.

## Команды

```
pnpm run lint         # Biome: линт + формат
pnpm run lint:fix     # автофикс
pnpm run typecheck    # tsc --noEmit
pnpm run test         # vitest run
pnpm run build        # tsc -> dist, + бит исполняемости на cli.js
pnpm run check        # всё подряд, как в CI
pnpm run hooks:install # git-хуки (lefthook)
```

## Правила

- Новый пакет — только после проверки: возраст последнего релиза, число мейнтейнеров, число транзитивных зависимостей, provenance. Минимизировать агрессивно; что решается встроенными средствами Node — решать встроенными.
- `pnpm install --frozen-lockfile`. Настройки `minimumReleaseAge: 10080`, `strictDepBuilds`, пустой `allowBuilds` не ослаблять без записи в ADR.
- Каждая фича ядра — с фикстурами и тестами.
- Нетривиальное решение — короткий ADR в `docs/adr/`: контекст, решение, альтернативы, последствия.
- Conventional commits.
- MCP-инструменты и внутренние источники работодателя в этом проекте не используются. Ничего оттуда — ни кода, ни конфигов, ни имён эндпоинтов, ни структур данных. Перечень конкретных серверов — в `.claude/rules/_local/`, который не версионируется: этим названиям не место в публичном репозитории.
