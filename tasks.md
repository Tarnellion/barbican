# Задачи

Фазы и критерии выхода — в [plan.md](plan.md).

## Сессия 2 — ядро (закрыта)

- [x] **ADR-0006:** ожидаемая матрица объявляется человеком, а не выводится из спеки.
- [x] Типы политики (`ExpectedAccessPolicy`) отдельно от наблюдённой матрицы.
- [x] `buildAccessMatrix` — сборка с проверкой целостности входа.
- [x] `diffAccess` — дифф с классификацией: эскалация, неожиданный отказ,
      непокрытая пара, ошибка обращения.
- [x] Фикстуры: два тенанта, три роли, четыре эндпоинта, «чистый» набор наблюдений.
- [x] `@vitest/coverage-v8` и пороги покрытия ядра, гейт в CI.

Осталось из этой темы:

- [ ] Селекторы эндпоинтов по шаблону метода и пути, а не только по списку `id`.
      На сотне эндпоинтов перечисление станет неподдерживаемым.
- [ ] Обнаружение cross-tenant утечек. Требует привязки ресурса к тенанту, а её
      неоткуда взять, пока не решён вопрос сбора идентификаторов (фаза 2).

## Сессия 3 — адаптеры

- [ ] Реализация `SpecParser` на `@apidevtools/swagger-parser` с `resolve: { file: false, http: false }`.
- [ ] **Блокирующее:** тест-доказательство, что внешние `$ref` не резолвятся — отдельно
      для `http(s)://` и для `file://` / относительного пути. Без него адаптер не принимается.
- [ ] Тест на YAML-бомбу: лимит размера и глубины входного документа.
- [ ] Реализация `HttpClient` на встроенном global fetch (не отдельный undici).
- [ ] Реализация `Throttle`: конкурентность, RPS, потолок на прогон, экспоненциальный
      backoff, circuit breaker на серии 5xx/429, уважение `Retry-After`.
- [ ] Проверить и добавить пакеты: `@apidevtools/swagger-parser`, `p-limit`, `p-queue`
      (возраст релиза, мейнтейнеры, транзитив, provenance).

## Сессия 4 — CLI и вывод

- [ ] Обязательный allowlist хостов: без него инструмент отказывается работать.
- [ ] Флаг `--unsafe-methods`; по умолчанию только GET и HEAD.
- [ ] JSON-отчёт как единственный источник истины.
- [ ] Редакция чувствительных данных по хардкод-путям (`fast-redact` или `@pinojs/redact`;
      учесть, что `fast-redact` мутирует исходный объект).
- [ ] Версия CLI из `package.json` вместо константы `VERSION` в `src/cli.ts`.
- [ ] Проверить и добавить пакеты: `zod`, `pino`, `fast-redact`, `picocolors`.

## Фаза 2 — валидация на публичных полигонах

- [ ] **ADR (блокирующее для этого класса детекторов):** сбор идентификаторов из тел
      ответов против запрета хранить тела. Часть BOLA достижима только по `id` из
      предыдущего ответа. Направление: извлечение отдельных значений по заданным в коде
      путям в кратковременный пул в памяти, не попадающий в отчёт.
- [ ] **ADR:** единый формат машиночитаемого ground-truth — общий для VAmPI, crAPI
      и своей платформы, иначе валидация не переиспользуется.
- [ ] docker-compose с VAmPI. Прогон с **выключенными** уязвимостями обязан дать ноль
      находок — это первичный критерий, важнее обнаружения.
- [ ] Прогон против crAPI, сверка с задокументированными BOLA/IDOR.
- [ ] Juice Shop — по остаточному принципу.

## Фаза 3 — мультитенантность

- [ ] Минимальная референс-платформа: 3–4 эндпоинта, два тенанта, три переключаемых

      IDOR по прямому идентификатору). Нужен оракул, а не платформа.
- [ ] Машиночитаемый ground-truth с ожидаемой матрицей доступа.

- [ ] Документация пользователя: аккаунты, ожидаемая матрица, scope.
