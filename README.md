# barbican

CLI-инструмент и библиотека для автоматизированной проверки RBAC и изоляции тенантов
в API мультитенантных платформ. На вход — OpenAPI-спецификация или список эндпоинтов
плюс набор аккаунтов с разными ролями и тенантами. Инструмент перебирает матрицу
«роль × эндпоинт», строит фактическую матрицу доступа, сравнивает её с ожидаемой и
показывает расхождения: privilege escalation, BOLA/IDOR, утечки между тенантами.
Безопасен по умолчанию — без явного флага выполняет только GET и HEAD, требует
явного allowlist хостов и не сохраняет тела ответов.

**Статус:** ранняя разработка, публичного API пока нет.

## Разработка

```bash
corepack enable pnpm
pnpm install
pnpm run hooks:install   # git-хуки; требует gitleaks (brew install gitleaks)
pnpm run check           # lint + typecheck + test + build
```

Лицензия: Apache-2.0.
